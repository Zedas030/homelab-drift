# Changelog

This is the changelog of the Homelab-Drift tool itself. The changelog of your homelab is generated by the tool
(`/var/lib/homelab-drift/repo/CHANGELOG.md` and `changelog.html`).

## 1.1.0 - 2026-11-05

- Redesigned web docs: shared homelab theme, light/dark toggle, optional dashboard link.
  - Every generated page (overview, hosts, services, ports, changelog) uses the shared theme: top bar with tabs and
    icons, a status card on the overview that says in one sentence whether the docs match the system, KPI tiles,
    findings and inventory as tables with status pills. Works on phones down to 375 px.
  - The CSS is written to `www/assets/` next to the pages (`homelab-theme.css`, `drift.css`).
  - New optional settings `ui.home_url` (default empty = no button) and `ui.home_label` (default `Dashboard`).

## 1.0.0

- First release: documentation generated from the real system state, drift detection with instant alerts and a daily
  digest via Home Assistant, acknowledgements, git snapshots, Prometheus metrics.
